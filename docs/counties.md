# County ordinances

County law is not a second copy of the state code. These notes are document-only. A commercial host (Municode, American Legal, General Code) is a finding, not a source we crawl.

The usual pattern is one county site, or a link out to a commercial host, with no state bulk file. Exceptions are called out below.

| State | Units | Where the ordinances actually are |
| --- | --- | --- |
| Alabama | 67 counties | Each county. Title 45 is legislative local laws, not commission ordinances |
| Alaska | 19 organized boroughs | Each borough, usually via a commercial host. Census areas do not legislate |
| Arizona | 15 counties | Each county. Example: [Maricopa ordinances](https://www.maricopa.gov/733/Ordinances) |
| Arkansas | 75 counties | Each quorum court. Example: Pulaski County |
| California | 58 counties | Each county, commonly linking to Municode |
| Colorado | 64 counties | Each county. No state host |
| Connecticut | 8 geographic counties | No county government since 1960. Ordinances are municipal |
| Delaware | 3 counties | Each county. New Castle and Kent link to commercial hosts. Sussex posts enacted ordinances |
| Florida | 67 counties | Each board must keep a codification. Filing with the state is not a public corpus |
| Georgia | 159 counties | Each county. No state host |
| Hawaii | 4 counties + Kalawao | Counties are the local governments. Some self-host, some link out |
| Idaho | 44 counties | Each county. Pending copies on county sites. Codified text often commercial |
| Illinois | 102 counties | Each county. Cook links out. Some counties self-publish HTML |
| Indiana | 92 counties | Each county. Some post on in.gov county pages |
| Iowa | 99 counties | Each county. Mix of county PDFs and commercial hosts |
| Kansas | 105 counties | Each county. Example: Douglas County PDFs. No state host |
| Kentucky | 120 counties | Fiscal-court pages on county sites, or a commercial host |
| Louisiana | 64 parishes | Parish sites or a commercial host. The state site is a directory only |
| Maine | 16 counties | Counties have narrow power. Towns hold most ordinances. No state host |
| Maryland | 23 counties + Baltimore City | [MD Courts index](https://www.mdcourts.gov/lawlib/research/gateway-to-md-law/county-codes) is links only |
| Massachusetts | Geographic counties | Most county governments are abolished. Remaining counties publish on their own sites. [SOS](https://www.sec.state.ma.us/divisions/cis/government/gov-county.htm) |
| Michigan | 83 counties | Per county. The state library points at commercial hosts |
| Minnesota | 87 counties | Per county. [Law Library index](https://mn.gov/law-library/research-links/ordinances.jsp) is links only |
| Mississippi | 82 counties | Short lists or PDFs on county sites |
| Missouri | 114 counties + St. Louis City | Per county. Jackson County self-hosts PDFs |
| Montana | 56 counties | Each county. No state host |
| Nebraska | 93 counties | Each county. No state host |
| Nevada | 17 counties | Each county. Clark posts a code page; many others link to Municode |
| New Hampshire | 10 counties | Towns hold most codes. Coos posts land-use rules for unincorporated places |
| New Jersey | 21 counties | [DCA directory](https://datahub.dca.nj.gov/documents/34c358d0ee874d21acf8ad20654edfdd) is links only |
| New Mexico | 33 counties | County sites or a commercial host. NMAC is state rules, not county ordinances |
| New York | 62 counties | [DOS Local Law Search](https://dos.ny.gov/local-law-search) files local laws since 1998 and county codes since 2015. Older filings are paper |
| North Carolina | 100 counties | Each county. [nc.gov](https://www.nc.gov/your-government/county-government-websites) is a directory |
| North Dakota | 53 counties | Per county, often the newspaper plus a thin PDF. No state library |
| Ohio | 88 counties | Per county. Example: [Cuyahoga County Code](https://cuyahogacounty.gov/code) |
| Oklahoma | 77 counties | Limited county rules on county sites. No general ordinance corpus |
| Oregon | 36 counties | County sites, for example [Multnomah](https://multco.us/info/multnomah-county-code) |
| Pennsylvania | 67 counties | Each county, often linking to a commercial host |
| Rhode Island | 5 geographic counties | No county government. Ordinances are city and town only |
| South Carolina | 46 counties | Clerk of council must keep a code. Most online copies are commercial hosts |
| South Dakota | 66 counties | Each county site. Some also use Municode |
| Tennessee | 95 counties | Per county. [CTAS website index](https://www.ctas.tennessee.edu/counties_websites) |
| Texas | 254 counties | Limited ordinance power. Per county. [State Law Library guide](https://guides.sll.texas.gov/texas-law/local-ordinances) |
| Utah | 29 counties | County sites. Archives keeps some filed copies, not a living code |
| Vermont | 14 counties | Counties do not enact ordinances. Towns and cities do. [24 V.S.A. § 1](https://legislature.vermont.gov/statutes/section/24/001/00001) |
| Virginia | 95 counties + 38 independent cities | Each locality. No state corpus |
| Washington | 39 counties | Each county. [King County Code](https://kingcounty.gov/en/dept/council/governance-leadership/county-legislation-codes/king-county-code) is self-hosted HTML |
| West Virginia | 55 counties | Ordinance PDFs on county sites, not one commercial library |
| Wisconsin | 72 counties | Each county. The [State Law Library index](https://wilawlibrary.gov/topics/ordinances.php) is links, plus a CSV of those links |
| Wyoming | 23 counties | County regulations and resolutions on county sites |

Every state has been checked. None has a government-hosted corpus of all county ordinances. New York's filed local laws are the closest. Until that changes, county codes stay off the indexer.
