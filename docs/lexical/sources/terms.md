# Established words

These phrases are taken from the markdown in this folder. Each row names the file that holds the sentence. A parser can treat the word as settled when the sentence is in that file.

| Phrase | Settled meaning | File |
| --- | --- | --- |
| section | The basic unit of a bill and of an enacted statute. Each section shall be numbered, and shall contain, as nearly as may be, a single proposition of enactment. | [usc-1-104.md](usc-1-104.md), [holc-guide.md](holc-guide.md) part III |
| subsection `(a)` | The first unit inside a section. A lower-case letter. | [holc-guide.md](holc-guide.md) part III; [house-manual-2022.md](house-manual-2022.md) page 20 |
| paragraph `(1)` | The unit inside a subsection. An Arabic numeral. | same |
| subparagraph `(A)` | The unit inside a paragraph. An upper-case letter. | same |
| clause `(i)` | The unit inside a subparagraph. A lower-case Roman numeral. | same |
| subclause `(I)` | The unit inside a clause. An upper-case Roman numeral. | same |
| item `(aa)` | The unit inside a subclause. The House manual adds this level. The online guide stops at subclause. | [house-manual-2022.md](house-manual-2022.md) page 20 |
| subitem `(AA)` | The unit inside an item. | same |
| title, subtitle, chapter, subchapter, part, subpart | Units above a section. The House manual also uses division above title in an omnibus bill. | [holc-guide.md](holc-guide.md) part III; [house-manual-2022.md](house-manual-2022.md) pages 18–19 |
| nest | If a unit is subdivided, any further subdivision must nest inside the preceding subdivision. A subparagraph sits inside a paragraph, not beside it. | [house-manual-2022.md](house-manual-2022.md) page 20 |
| unique section number | Best practice. An omnibus bill may repeat a section number, and the manual says that is acceptable. A later cite then names the division. | [house-manual-2022.md](house-manual-2022.md) page 19 |
| this Act / this division | Inside a division that repeats section numbers, a reference to “this Act” may need to be “this division”. | same |
| general rule, exceptions, special rules, transitional rules, definitions, effective date | The usual order of content inside a draft. The office does not always follow it. | [holc-guide.md](holc-guide.md) part IV; [house-manual-2022.md](house-manual-2022.md) page 18 |
| bill | In the Joint Rules, “bill” includes a resolution ratifying a proposed amendment to the United States Constitution and a resolution calling for a constitutional convention. | [joint-rules-2019.md](joint-rules-2019.md) rule 4 |
| digest | A bill may not be introduced unless the Legislative Counsel has attached the cover and a digest. | [joint-rules-2019.md](joint-rules-2019.md) rule 8.5 |
| California Style Manual / The Bluebook | Citations in a document filed in the courts must follow one of these, consistently. | [crc-1-200.md](crc-1-200.md) |
| heading | Division, part, chapter, article, and section headings shall not govern, limit, modify, or affect the scope, meaning, or intent of the provisions. | [wic-6.md](wic-6.md) |
| section (California code) | A section of that code unless some other statute is specifically mentioned. | [puc-10.md](puc-10.md) |
| subdivision | A subdivision of the section in which that word occurs unless some other section is expressly mentioned. California uses this word for `(a)`. The House guide calls `(a)` a subsection. | [puc-10.md](puc-10.md) |

The House PDF extraction keeps the printer’s running headers and line breaks. The Joint Rules file is Senate Concurrent Resolution 1 of the 2019–20 session, which is the resolution that adopted those rules.
